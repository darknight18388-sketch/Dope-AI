# Dope-AI

Personal AI assistant (Jarvis-style) running on Linux.

## Setup
```bash
git clone https://github.com/darknight18388-sketch/Dope-AI.git
cd Dope-AI
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Add your Gemini API key in `config/api_keys.json` (never commit this file), then run:

```bash
python main.py
```
